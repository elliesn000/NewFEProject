# News Frontend Clone

A responsive frontend clone of the [VnExpress International](https://e.vnexpress.net/) news website.

---

## 📁 Repository Structure

```text
├── Basic/          # HTML5, CSS (Grid/Flexbox), and JavaScript
└── news-angular/   # Angular, Angular Material, and Tailwind CSS

```

---

## Projects Overview

### 1. Basic Version (`/Basic`)

This version focuses on fundamental web development concepts without external libraries or frameworks.

* **HTML5 & CSS3:** Structured layout built using CSS Grid and Flexbox for high responsiveness.
* **Styling Architecture:** Implements global reusable styles alongside custom component styling for specific web elements.
* **JavaScript:** Demo feature dropdown menu at Trending tab

### 2. Angular Version (`/news-angular`)

An modernized, refactored version aimed at improving code maintainability, clean code practices, and development speed.

* **Angular:** Component-based architecture separating logic, template, and styles.
* **Angular Material:** Utilized for accessible, pre-built UI components.
* **Tailwind CSS:** Provides CSS styling for rapid UI development and precise layout tweaks.


## Key Features

* **Interactive Navigation:** UI elements and homepage dropdown menus.
* **Article Submission:** Authors can draft and submit new articles.
* **Admin Moderation:** Admins can review, approve, or reject pending posts.
